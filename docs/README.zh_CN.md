# DSH 插件更新工具

一个 Qt 桌面小工具：自动索引 DeepSeek Harness（DSH）各 profile 下已安装的插件，
对比 npm 注册表最新版本，一键批量更新（通过官方 `dsh plugin` 命令执行）。

主要功能：

- 自动扫描 `~/.dsh/profiles/*/package.json`，列出全部已安装插件
- 每行显示：包名 / Profile / 安装源 / 现版本 / 最新版本 / 状态 / 安装目录
- npm 源自动查询最新版并预勾选可更新项；Git 源标记"无法检查"
- 一键更新全部 / 更新选中，串行执行，实时日志
- 列表右键：选择 / 取消选择 / 打开插件目录 / 复制包名 / 复制安装源
- 关于 / 更新说明 / 退出
